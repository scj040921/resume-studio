# 安卓版与电脑同步

安卓版 `拾简-Android-0.9.3.apk` 支持 Android 8.0（API 26）及以上，使用系统 Android System WebView。请保持系统 WebView 更新。APK 为通用架构，无需电脑服务常驻；资料在手机应用私有目录离线存储。

## 安装和开始使用

1. 把 APK 传到手机，允许所用文件管理器安装应用，打开 APK 完成安装。
2. 电脑使用配套 0.9.3 或更新版本，手机和电脑分别进入“设置与同步 / 跨端同步 · WebDAV”。
3. 在 WebDAV 服务器预先建立个人目录，两端填写同一个最终 HTTPS 目录地址、用户名和应用密码。保存配置。
4. 先在资料完整的一端点“检查并同步”上传；另一端检查时如出现首次关联差异，比较大小和文件修改时间后选择“保留云端并下载”。
5. 后续编辑完成后手动同步，再到另一端同步。两端资料不同时都需要明确选择保留版本，整套替换，不能合并两套不同修改。

支持强 ETag 的服务使用条件 PUT；缺失或弱 ETag 时使用内容指纹及上传回读，拒绝通配条件的服务会在再次确认内容未变后兼容重试。无强 ETag 时请同一时间只在一台设备同步。电脑端可自动创建同步目录；手机填写电脑设置中保存的同一实际目录。不会跟随重定向，不要填写分享链接。WebDAV 文件是明文 JSON，包含个人简历、照片和面试资料，请使用个人目录。仅自动化离线验证允许 `localhost` / `127.0.0.1` 的 HTTP。

## 同步范围与保护

简历、照片、历史、收藏、投递快照与时间线、日程、公司来源、面试题库/答案/掌握进度及非敏感设置同步。Cookie、网站会话、AI Key、WebDAV 密码和已导出的 PDF 不上传。安卓凭据使用 Android Keystore 的 AES-GCM 加密，系统备份禁用；手机和电脑需分别配置密钥。

同步沿用 v1 核心文件 `resume-studio.sync.json`。面试资料放在 `extensions.interviewStudy = {version:1,decks:[...]}`。两端把它纳入内容基线、校验、CAS、下载前备份和中断恢复；旧客户端会保留该扩展但不能编辑它。读取没有此扩展的旧包时保留本机题库，再上传时写入扩展，不把“没有扩展”当成删除。需要双向同步题库时电脑端和手机端都升级。手机同步状态显示本机/云端题库数量，便于确认题库和背诵进度是否进入同步快照。

Android 可启用每 30 分钟后台检查。系统只在网络可用时运行任务；应用在前台时任务会延后。两端一致时无需同步；任何差异（包括首次上传和单端变化）都等待用户打开“检查并同步”，比较资料大小、相对上次同步的增减和实际文件修改时间后确认版本。后台任务不自动覆盖资料。首次同步没有大小基线，旧基线未记录大小或云端未提供修改时间会显示未知。下载前保留整包备份，取消不替换任一端。

安卓更新使用桌面端相同的 GitHub `stable.json` / `nightly.json` 签名通道、RSA-PSS 公钥校验和 SHA-256 安装包摘要。下载完成后由 Android PackageInstaller 安装，首次需允许拾简安装未知应用。Release 的签名元数据覆盖对应 Android APK 的文件名、大小、摘要和版本码。

正式版和 Nightly 均在 GitHub Release 附带 APK。测试版应先安装 Nightly 并验收，再从同一源码升级 Stable。

下载替换前备份完整资料到私有数据目录的 `sync-backups/`。手机“设置 → 查看同步备份”可恢复本机；恢复后重新检查同步。卸载 Android 应用会删除本机数据与密钥，卸载前请确认已同步。

## 开发、构建和验证

入口为 `scripts/build-android.ps1`，需要 JDK 21、Android SDK platform 35/build-tools 36.0.0。无需 Gradle。脚本从原 Java 源生成 Android API 兼容调用，复用原校验、原子存储、历史、招聘适配与详情解析；HTTP 服务器壳不进入 APK，网络改用 HttpURLConnection。HTML/CSS 手机界面只在受控本机 HTTPS 虚拟来源运行；外站 WebView 没有原生数据桥。模板 CSS 与 BOSS/牛客单条详情提取脚本直接从电脑端源生成。

构建时校验固定版本 PDFBox Android 2.0.27.0 的 SHA-256。字体与模板的原始许可证随包保留。默认本机签名文件保存在 `%USERPROFILE%\.android\resume-studio-local.p12`，不进入仓库；后续覆盖安装必须保留这份签名文件。外部签名可传 `-SigningStore/-SigningAlias` 并设置环境变量 `RESUMESTUDIO_ANDROID_STORE_PASS`。APK 与测试夹具只进入 `release/`、`artifacts/`。

```powershell
./scripts/build-android.ps1
./scripts/test-android-sync.ps1
./scripts/test-android-ui.ps1 -Device emulator-5554
./scripts/build.ps1 -ReleaseDirectory release/ResumeStudio-0.9.3
./scripts/test-features.ps1
```

`test-android-sync.ps1` 还执行实际 app.js 比较窗口的主机 DOM 测试（默认取消、返回键取消、任一版本选择、无云端版本和未知元数据）。它使用真正的桌面 C# 同步器、Java 存储和安卓 Java 同步器，经实际 loopback HTTP DAV 验证互操作，包括面试题库与背诵状态双向往返。`test-android-ui.ps1` 以独立 instrumentation APK 驱动正式签名 APK，检查真实 WebView/存储/Keystore，并通过 adb reverse 测试手机运行时的条件上传/回读；验证 APK 不包含测试桥或调试模式。

公网 WebDAV 服务、用户的真机系统文件选择器、真实招聘网站登录/验证码和用户配置的 AI 服务仍需分别验收。模拟器通过不代表这些外部环境已经验证。

无强 ETag 的服务不能提供原子的版本覆盖保护，应同一时间只在一台设备同步。部分服务拒绝通配 If-Match 覆盖时，两端会重新读取并确认字节未变，再以内容校验兼容上传；真实内容变化或删除仍拒绝旧同步计划。链接、账号和凭据仅保存在本机，不进入同步资料、源码、测试夹具或发行包。
